지정된 경기 JSON 파일을 읽어서 인스타 릴스용 30초 나레이션 대본을 작성해줘.

규칙:

- 총 단어 수 75~90단어
- 구성: 훅(3초) → 경기요약(12초) → MOM/평점(7초) → 순위변동(6초) → 마무리훅(2초)
- 스코어는 도입부에 바로 공개하지 말고 궁금증을 유발하는 문장으로 시작
- 결과에 대한 유머 1~2개 포함 (선수/감독 인신공격 절대 금지)
- 캡션과 해시태그도 같이 작성 (해시태그 8~12개, 팀명/리그명/선수명 포함)
- 경기 데이터에 "확인 필요" 표시가 있으면 단정하지 말고 완곡하게 처리

다음 두 파일로 저장해줘:

1. `output/instagram/[날짜]/[경기ID]_script.md` — 아래 순서로 포함:
   - 맨 위에 YAML 프런트매터로 승인 상태 표시 (자동 게시 파이프라인이 이 값을 읽음):
     ```
     ---
     matchId: [경기ID]
     platform: instagram
     status: pending_approval
     ---
     ```
   - 구간별 타임코드가 표시된 나레이션 대본
   - 게시용 캡션
   - 해시태그 목록
2. `output/instagram/[날짜]/[경기ID]_subtitles.srt` — 나레이션 텍스트를 대본의 구간
   타임코드(훅/경기요약/MOM평점/순위변동/마무리훅)에 맞춰 SRT 자막으로 만들어줘.
   이 파일은 나중에 TTS 음성 합성과 영상 자막 번인에 그대로 사용된다.

`status`는 사람이 검수 후 `/approve [경기ID]`를 실행하기 전까지는 항상
`pending_approval`로 둔다 — 이 커맨드가 직접 `approved`로 쓰지 않는다.
