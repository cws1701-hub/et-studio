`data/matches/[경기ID].json` 파일을 읽어서 인스타 릴스용 30초 나레이션 대본을 작성해줘.

규칙:

- 총 단어 수 75~90단어 (한국어 기준 음절수로 환산해서 30초 분량 맞추기)
- 구성: 훅(0~3초) → 경기요약(3~15초) → MOM/평점(15~22초) → 순위변동(22~28초) → 마무리훅(28~30초)
- 톤: 캐스터 70% + 예능 자막 30%, 구어체 ("~했죠", "~인데요")
- 스코어는 도입부에 바로 공개하지 말고 궁금증을 유발하는 문장으로 시작
- 결과에 대한 유머 1~2개 포함 (선수/감독 인신공격, 국적·인종 관련 드립 절대 금지)
- 캡션과 해시태그도 함께 작성 (해시태그 8~12개, 팀명/리그명/선수명 포함)
- 실제 경기 영상은 사용하지 않고 자체 제작 그래픽(스탯카드, 순위표, 타임라인) 연출을 전제로 대본 작성
- 경기 데이터에 "확인 필요" 표시가 있으면 해당 부분은 대본에서 단정하지 말고 표현을 완곡하게 처리

`output/instagram/[날짜]/[경기ID]_script.md`로 저장해줘. 파일에는 다음을 포함해줘:

1. 구간별 타임코드가 표시된 나레이션 대본
2. 게시용 캡션
3. 해시태그 목록
