지정된 경기 JSON 파일을 읽어서 네이버 블로그 포스팅을 작성해줘.

규칙:

- 전체 3000자 이내
- 구성: 훅 도입부(250자) → 경기요약(900자) → [영상 삽입 위치 표시] →
  MOM/평점(450자) → 순위표 코멘트(300자) → 마무리(250자)
- 제목은 클릭 유도형으로, 결과를 완전히 스포하지 않게 작성
- 하이라이트 영상은 다운로드하지 말고, "[여기에 구단/리그 공식 채널 하이라이트 영상 임베드]"
  문구로 대체
- 말투는 친근한 구어체, 이모지 적당히 사용
- 결과에 대한 유머는 가볍게 1개 정도만 (선수/감독 인신공격 절대 금지)
- 경기 데이터에 "확인 필요" 표시가 있으면 단정적으로 쓰지 말고 완곡하게 처리

`output/naverblog/[날짜]/[경기ID]_post.md`로 저장해줘. 파일에는 다음을 포함해줘:

1. 제목
2. 본문 (위 구성 순서대로)
