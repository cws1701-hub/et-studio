`data/matches/[경기ID].json` 파일을 읽어서 유튜브용 1분 영상 대본을 작성해줘.

규칙:

- 총 나레이션 150~180단어, 60초 분량
- 구성: 훅(0~5초) → 경기 전체 타임라인 리뷰(5~35초) → MOM/평점(35~45초) →
  리그 순위 변동(45~55초) → 마무리/구독 유도(55~60초)
- 화면에 들어갈 자막 텍스트를 나레이션과 별도로 타임코드와 함께 작성
  (형식: `[00:03] "홀란드 오늘도 인간 아님 ㄷㄷ"`)
- 강조할 키워드(스코어, 선수명, 숫자)는 자막에서 **굵게** 표시
- 웃긴 포인트에는 이모지/효과 자막("ㄷㄷㄷ", "실화냐", "각성")을 1~2군데만, 과하지 않게 삽입
- 결과에 대한 유머 요소 1~2개, 선수/감독 인신공격 절대 금지
- 실제 방송 영상 대신 자체 그래픽(스탯카드, 순위표, 타임라인) 연출 기준으로 작성
- 경기 데이터에 "확인 필요" 표시가 있으면 단정하지 말고 완곡하게 처리

다음 두 파일로 저장해줘:

1. `output/youtube/[날짜]/[경기ID]_script.md` — 구간별 나레이션 대본 + 타임코드 자막 목록
2. `output/youtube/[날짜]/[경기ID]_subtitles.srt` — 나레이션 기준 SRT 자막 파일
