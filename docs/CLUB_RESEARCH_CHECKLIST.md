# 구단 리서치 체크리스트

새 구단을 `data/clubs/`에 추가하기 전 아래 항목을 순서대로 확인합니다.
확인이 안 된 항목은 YAML에 `unknown`으로 남기고 넘어갑니다 (추측 금지).

## 기본 정보
- [ ] 정식 명칭 (일본어/한국어 표기)
- [ ] 소속 (J리그 클럽 산하 클럽유스 / 학교 축구부 등)
- [ ] 소재지 (도도부현, 시)
- [ ] 창단연도
- [ ] 공식 웹사이트, 공식 SNS(인스타그램/X/유튜브)

## 육성 시스템
- [ ] 카테고리(U-12/U-15/U-18) 및 소속 리그(클럽유스선수권, 프린스리그 등)
- [ ] 훈련 시설, 훈련 빈도
- [ ] 코칭스태프 주요 이력 (공개된 경우만)

## 생활 여건
- [ ] 기숙사 유무 및 형태 (구단 공식 확인 필수)
- [ ] 통학/제휴 학교 여부

## 진로
- [ ] 유스 출신 프로 선수 (출처 있는 경우만 기재, 위키/구단 공식 발표 등 1차 출처)

## 유학/국제 학생 관련 (가장 신중하게 다룰 항목)
- [ ] 외국인 선수/유학생 수용 이력 (언론 보도, 구단 공식 발표 기준)
- [ ] 입단 테스트 절차 및 시기
- [ ] 비자/체류 관련 안내 창구 (구단이 직접 안내하는지, 제휴 에이전시가 있는지)
- [ ] 학비/기숙사비 (공식 확인 전까지 기재 금지)
- [ ] 문의 창구 (이메일/폼)

## 출처 기록
- [ ] 각 항목마다 URL 또는 "구단 문의 (날짜, 답변자, 방법)" 형식으로 출처 기록
- [ ] `verification.status`를 draft/partial/verified 중 하나로 갱신
