# 네이버 블로그 반자동 발행 가이드

## 왜 완전자동이 아닌가

네이버는 블로그 **글쓰기(작성/발행)를 위한 공식 오픈 API를 제공하지 않습니다**
(검색 API 등 읽기 전용 API만 존재). 브라우저 자동화(셀레니움 등)로 로그인 후
글쓰기를 대행하는 방식은 기술적으로는 가능하지만 네이버 이용약관 위반 소지가
있고, 이상행위로 탐지되어 계정이 제재(로그인 제한, 게시 제한 등)될 위험이
있습니다. 이 프로젝트는 그 위험을 감수하지 않고 **반자동 워크플로우**를
사용합니다.

## 반자동 워크플로우

1. `python scripts/generate_blog_post.py --club <id> --topic <topic>` 로 블로그
   본문 초안(Markdown)을 생성합니다. `content/<club_id>/blog/<topic>.md`에 저장됩니다.
2. 사람이 초안을 검수/수정합니다 (특히 `[확인 필요]` 표시가 있는 부분).
3. `python scripts/naver_export.py --club <id> --topic <topic>` 를 실행하면
   본문을 **네이버 블로그 스마트에디터에 붙여넣기 좋은 형태**로 정리한
   HTML 미리보기 파일(`content/<club_id>/blog/<topic>_naver_preview.html`)이 생성됩니다.
4. 그 HTML 파일을 브라우저로 열어 본문을 전체 선택(Ctrl+A) → 복사(Ctrl+C).
5. 네이버 블로그 스마트에디터 새 글 작성 화면을 열고 붙여넣기(Ctrl+V).
   - 이미지는 스마트에디터가 붙여넣기 시 자동으로 인식하지 못할 수 있으므로,
     `content/<club_id>/images/`에 있는 원본 이미지를 별도로 드래그 앤 드롭하는
     것을 권장합니다. HTML 미리보기에는 이미지가 들어갈 위치와 캡션이
     `[이미지: 파일명 — 설명]` 형식으로 표시됩니다.
6. 태그, 카테고리 확인 후 발행 버튼은 사람이 직접 클릭합니다.

## 다음 단계로 자동화를 더 밀어붙이고 싶다면

- 네이버 블로그가 아닌 **네이버 포스트/네이버 인플루언서 검색엔진 최적화**
  구조로 전환하거나, 자체 홈페이지(예: GitHub Pages, 티스토리 — 티스토리는
  공식 오픈 API로 글쓰기 자동화 지원)를 메인 채널로 병행하는 방법도 있습니다.
  필요하면 이 부분도 설계해 드릴 수 있습니다.
- 브라우저 자동화(비공식) 방식을 정말로 원하면 리스크를 분명히 안내한 뒤
  별도로 구현 여부를 다시 확인하겠습니다. 기본값은 반자동입니다.
