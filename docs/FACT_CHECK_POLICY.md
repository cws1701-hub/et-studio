# 사실 검증 정책

이 프로젝트는 학부모의 자녀 유학 결정에 영향을 줄 수 있는 정보를 다룹니다.
잘못된 정보(학비, 기숙사, 입단 조건, 유학생 수용 여부 등)는 실제 피해로
이어질 수 있으므로 아래 규칙을 반드시 지킵니다.

## 규칙

1. **모든 구단 YAML은 `verification` 블록을 포함해야 한다.**
   - `status`: `draft`(미검증) / `partial`(일부 검증) / `verified`(공식 확인)
   - `last_checked`: 최종 확인일
   - `notes`: 무엇이 확인되었고 무엇이 안 되었는지

2. **각 사실 항목은 `sources`에 근거 URL 또는 문의 기록을 남긴다.**
   출처가 없는 항목은 콘텐츠에서 "확인 필요" 또는 "구단 공식 문의 결과 추후 업데이트"로
   명시하고, 단정적으로 쓰지 않는다.

3. **유학 관련 항목(`study_abroad.*`)은 기본값이 `unknown`이다.**
   구단 공식 채널(웹사이트, 이메일, 전화 문의)을 통해 직접 확인하기 전까지
   "받는다/안 받는다", "학비는 얼마다" 같은 단정적 문구를 콘텐츠에 쓰지 않는다.

4. **콘텐츠 생성 스크립트(`generate_blog_post.py`, `generate_reels_script.py`)는
   `verification.status`가 `draft`인 항목을 자동으로 "확인 필요" 문구와 함께
   출력한다.** 사람이 검증 후 `verified`로 바꾸기 전까지 확정적 표현을 쓰지 않는다.

5. **졸업생/알럼나이 정보는 개인정보이므로 공개된 1차 출처(구단 공식 발표,
   기사)가 있을 때만 싣는다.** 추측이나 커뮤니티 소문은 사용하지 않는다.

6. **법률/제도 관련 언급(비자, 유학 알선 등)은 일반 정보 제공 수준으로만 다루고,
   개별 법률 자문이 필요하다는 점을 명시한다.**
