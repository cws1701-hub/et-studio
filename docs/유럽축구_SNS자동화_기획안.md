# 유럽축구 하이라이트·리뷰 SNS 자동화 기획안
### (인스타 릴스 / 네이버 블로그 / 유튜브 — 클로드 코드 자동화용)

---

## 0. 시작하기 전에 — 저작권 리스크 안내

이 기획은 **"경기 영상을 직접 재업로드"하지 않고, 자체 제작 그래픽·자막·나레이션으로 리뷰를 만드는 방식**을 기본으로 설계했습니다.

| 리스크 높음 (피해야 함) | 리스크 낮음 (이 기획의 방식) |
|---|---|
| 방송사 하이라이트 영상 다운로드 후 편집·재업로드 | 자체 제작 스탯 그래픽 + 평점 카드 + 순위표 애니메이션 |
| 중계 화면 캡처 영상 사용 | 경기장·선수 사진(라이선스 프리 소스) 활용 |
| 골 장면 무단 편집본 | 텍스트 기반 골 타임라인 + 효과음 + 나레이션 |
| 저작권 있는 배경음악(응원가 등) | 무료/로열티 프리 BGM |

만약 실제 경기 영상을 꼭 넣고 싶다면, 구단·리그가 자사 SNS에 올린 공식 영상을 **"임베드/링크 공유"** 하는 방식(다운로드·재편집 없이)이 상대적으로 안전합니다. 자동화 스크립트에서도 이 원칙을 기본값으로 넣어뒀습니다.

---

## 1. 전체 파이프라인 구조

```
[1단계] 경기 데이터 수집
   ↓ (스코어, 평점, MOM, 순위, 주요 이벤트 시간)
[2단계] 대본 생성 (플랫폼별 3종)
   ↓ 클로드가 개그 요소 넣어서 대본 작성
[3단계] 비주얼 자산 제작
   ↓ 스탯 카드, 순위표, 타임라인 그래픽 (자체 제작)
[4단계] 나레이션 + 자막
   ↓ TTS 음성 생성 + SRT 자막 파일
[5단계] 영상 조립
   ↓ 그래픽 + 나레이션 + 자막 합성 (플랫폼별 길이/비율 맞춤)
[6단계] 게시 대본 + 캡션 + 해시태그 세트 생성
   ↓ (실제 업로드는 각 플랫폼 정책상 수동 확인 후 진행 권장)
```

**핵심 원칙**: 클로드 코드는 1~4, 6단계(데이터 정리, 대본, 자막, 캡션)를 100% 자동화하고, 5단계(영상 렌더링)는 스크립트로 자동화하되, **최종 업로드는 사람이 한 번 확인 버튼을 누르는 구조**를 추천합니다. (계정 정지 리스크 + 콘텐츠 퀄리티 관리 차원)

---

## 2. 데이터 소스 (경기 결과·평점·순위)

자동화 첫 단계는 "오늘/이번 라운드 경기 데이터"를 가져오는 것입니다. 후보:

- **무료/공식형**: football-data.org (API, 무료 티어 있음), TheSportsDB
- **평점(Rating) 데이터**: WhoScored, SofaScore — 공식 API는 없지만 웹 데이터를 참고용으로 확인 후 직접 재해석한 자체 평점을 만드는 게 저작권상 더 안전합니다.
- **순위표**: football-data.org standings API로 자동 수집 가능

> 팁: 클로드 코드 안에서 "이 API로 오늘 5대리그 경기 결과를 가져와서 JSON으로 정리해줘" 같은 스크립트를 만들어두면, 매일 아침 한 번 실행으로 데이터 수집이 끝납니다.

## 3. 채널별 콘텐츠 포맷 설계

### 3-1. 인스타그램 릴스 (30초 이내)

**구조 (30초 = 약 75~90단어 나레이션)**

| 구간 | 시간 | 내용 |
|---|---|---|
| 훅 (Hook) | 0~3초 | 결과를 재밌게 비틀어서 던지는 한 줄 (스코어 먼저 보여주지 않기) |
| 경기 요약 | 3~15초 | 득점 타임라인 + 핵심 장면 코멘트 (개그 톤) |
| MOM 소개 | 15~22초 | 이 경기 MOM + 평점 + 왜 잘했는지 한 줄 |
| 순위 변동 | 22~28초 | 이 결과로 순위가 어떻게 됐는지 |
| 마무리 훅 | 28~30초 | 다음 경기 예고 + "저장/팔로우" 유도 멘트 |

**대본 템플릿 예시 (예: 맨시티 3-1 아스널 가상 상황)**

```
[0~3초] "아스널 팬 여러분... 오늘은 그냥 넷플릭스 보시는 걸 추천드립니다 😂"
[3~15초] "전반 12분 홀란드 선제골. 아스널 수비진 지금 GPS 고장난 듯
          후반 68분 케빈 더 브라위너 프리킥 추가골
          그리고 후반 80분... 사카가 만회골 넣긴 했는데 이미 늦었죠"
[15~22초] "오늘의 MOM은 홀란드! 평점 8.9점
           멀티골 + 결정적 순간마다 등장, 역시 괴물"
[22~28초] "이 결과로 맨시티는 승점 1위 탈환!
           아스널은 2위로 밀려나며 이번 주말 표정 관리 실패"
[28~30초] "다음 빅매치는 리버풀 vs 첼시! 저장해두고 같이 보시죠 🔥"
```

**나레이션 톤 가이드**: 캐스터 톤 70% + 예능 자막 톤 30%. "~했습니다" 격식체보다 "~했죠", "~인데요" 같은 구어체 + 감탄사 활용.

### 3-2. 네이버 블로그 (3000자 이내)

**구조**

1. 도입부 (200~300자): 재밌는 훅 문장 + 오늘 리뷰할 경기 소개
2. 경기 요약 (800~1000자): 득점 타임라인, 주요 장면 서술형 리뷰
3. 하이라이트 영상 삽입 (임베드 방식 — 공식 채널 영상 링크 or 자체 제작 요약 영상)
4. MOM & 평점 (400~500자): 이 경기 최고의 선수와 이유
5. 리그 순위표 (표 또는 이미지, 300자 내외 코멘트)
6. 마무리 + 다음 경기 예고 (200~300자)
7. SEO 키워드/해시태그

**SEO 키워드 예시**: `[팀명] 하이라이트`, `[팀명] vs [팀명] 리뷰`, `프리미어리그 순위`, `[선수명] 평점`

**대본 템플릿 예시 (도입부)**

```
제목: 맨시티 vs 아스널, 홀란드 원맨쇼에 무너진 아스널 (feat. 순위 대이동)

오늘 프리미어리그 빅매치, 다들 보셨나요?
저는 보면서 커피를 두 번이나 흘렸습니다. 그만큼 정신없는 경기였어요.
오늘은 맨시티 3-1 아스널 경기, 하이라이트부터 MOM, 그리고
이 결과가 순위표에 어떤 영향을 줬는지까지 싹 정리해드릴게요.
```

---

### 3-3. 유튜브 쇼츠/영상 (1분 이내)

**구조 (1분 = 약 150~180단어 나레이션)**

30초 릴스 구조를 확장한 버전 + **자막 필수 삽입** (모바일에서 무음 시청 비율이 높기 때문)

| 구간 | 시간 |
|---|---|
| 훅 | 0~5초 |
| 경기 전체 타임라인 리뷰 | 5~35초 |
| MOM + 평점 | 35~45초 |
| 리그 순위 변동 | 45~55초 |
| 마무리 + 구독 유도 | 55~60초 |

**자막 스타일 가이드**
- 화면 하단 1~2줄, 핵심 단어(스코어, 선수명, 숫자)는 강조색 처리
- 웃긴 포인트에는 이모지/효과 자막 ("ㄷㄷㄷ", "실화냐", "각성") 삽입 — 과하지 않게 1~2군데만

## 4. 개그 요소 삽입 가이드 (공통)

인기 스포츠 하이라이트 채널들이 조회수를 잘 뽑는 공통 패턴은 대체로:

1. **스코어를 바로 안 알려주고 궁금증 유발** ("오늘 아스널 팬들 표정이 안 좋습니다")
2. **선수를 캐릭터화** (별명, 밈 활용 — 예: "홀란드 오늘도 인간 아님")
3. **자책골·실수 장면은 웃음 포인트로, 비하는 X** (선수 인신공격은 피하고 상황 자체를 유머러스하게)
4. **패배팀 팬 시점 개그** ("~팬 여러분, 오늘은 조용히 넘어가시죠")
5. **숫자로 임팩트 주기** ("이번 시즌 무패 기록 13경기 만에 깨짐")

> 주의: 특정 선수·감독 비하, 인종/국적 관련 드립은 절대 금지. "결과에 대한 유머"와 "사람에 대한 조롱"은 다릅니다.

## 5. 클로드 코드 자동화 설계

### 5-1. 폴더 구조 (추천)

```
football-sns-automation/
├── CLAUDE.md                      # 프로젝트 전체 규칙 (아래 6번 참고)
├── .claude/
│   └── commands/                  # 슬래시 커맨드 모음
│       ├── collect-data.md
│       ├── write-instagram.md
│       ├── write-blog.md
│       ├── write-youtube.md
│       └── weekly-report.md
├── data/
│   ├── matches/                   # 경기별 원본 데이터 (JSON)
│   ├── standings/                 # 리그 순위 데이터
│   └── ratings/                   # 평점/MOM 데이터
├── scripts/
│   ├── fetch_matches.py           # 경기 데이터 수집
│   ├── build_graphics.py          # 스탯카드/순위표 이미지 생성
│   └── generate_tts.py            # 나레이션 음성 생성
├── output/
│   ├── instagram/[날짜]/
│   ├── naverblog/[날짜]/
│   └── youtube/[날짜]/
└── templates/
    ├── instagram_script.md
    ├── blog_template.md
    └── youtube_script.md
```

### 5-2. CLAUDE.md에 넣을 프로젝트 규칙 (예시)

```markdown
# 프로젝트: 유럽축구 SNS 리뷰 자동화

## 원칙
- 실제 방송 영상은 절대 다운로드/재편집하지 않는다. 
  영상이 필요하면 공식 채널 임베드 링크만 사용한다.
- 모든 영상은 자체 제작 그래픽(스탯카드, 순위표, 타임라인)으로 구성한다.
- 커버 대상: 프리미어리그, 라리가, 분데스리가, 세리에A, 리그1,
  UEFA 챔피언스리그, 유로파리그, 국가대표 A매치(유럽)
- 톤: 캐스터 70% + 예능 자막 30%. 구어체 사용.
- 선수/감독 인신공격 금지. 결과에 대한 유머만 허용.
- 인스타 릴스: 30초 이내 / 유튜브: 1분 이내 / 네이버 블로그: 3000자 이내
- 매 콘텐츠에 MOM, 평점, 리그 순위 변동 반드시 포함

## 데이터 소스
- 경기 결과/순위: football-data.org API
- 평점: 여러 소스 참고 후 자체 재해석하여 평점 부여 (특정 사이트 평점 그대로 복사 금지)
```

### 5-3. 슬래시 커맨드 예시 — 실제 프롬프트 내용

**`.claude/commands/collect-data.md`**
```markdown
오늘 날짜 기준으로 지난 24~48시간 내 종료된 다음 대회의 경기를 정리해줘:
프리미어리그, 라리가, 분데스리가, 세리에A, 리그1, 챔피언스리그, 유로파리그, 
그리고 진행 중이라면 유럽 국가대표 A매치.

각 경기마다 다음 항목을 JSON으로 정리해서 data/matches/에 저장해줘:
- 대회명, 홈팀, 원정팀, 스코어
- 득점 타임라인 (선수명, 시간)
- 주요 이벤트 (퇴장, PK, 자책골 등)
- 추천 MOM 선수와 이유 (직접 판단해서 근거 포함)
- 자체 평점 (10점 만점, 근거 1줄)
- 이 경기 결과로 바뀐 순위 정보

경기 데이터가 확인되지 않으면 추측하지 말고 "확인 필요"로 표시해줘.
```

**`.claude/commands/write-instagram.md`**
```markdown
data/matches/[경기ID].json 파일을 읽어서 인스타 릴스용 30초 나레이션 대본을 작성해줘.

규칙:
- 총 단어 수 75~90단어 (한국어 기준 음절수로 환산해서 30초 분량 맞추기)
- 구성: 훅(3초) → 경기요약(12초) → MOM/평점(7초) → 순위변동(6초) → 마무리훅(2초)
- 톤: 캐스터 70% + 예능 자막 30%, 구어체
- 스코어는 도입부에 바로 공개하지 말고 궁금증을 유발하는 문장으로 시작
- 결과에 대한 유머 1~2개 포함 (선수/감독 인신공격 금지)
- 캡션과 해시태그도 함께 작성 (해시태그 8~12개, 팀명/리그명/선수명 포함)
- 실제 경기 영상은 사용하지 않고 텍스트/그래픽 연출을 전제로 대본 작성

output/instagram/[날짜]/[경기ID]_script.md 로 저장해줘.
```

**`.claude/commands/write-blog.md`**
```markdown
data/matches/[경기ID].json 파일을 읽어서 네이버 블로그 포스팅을 작성해줘.

규칙:
- 전체 3000자 이내
- 구성: 훅 도입부(250자) → 경기 요약(900자) → [영상 삽입 위치 표시] → 
  MOM/평점(450자) → 순위표 코멘트(300자) → 마무리(250자)
- 제목은 클릭 유도형으로, 결과를 완전히 스포하지 않게 작성
- SEO 키워드 자연스럽게 3~5회 반복 배치 
  (예: "[팀명] 하이라이트", "[팀명] 순위", "[선수명] 평점")
- 하이라이트 영상은 다운로드하지 말고, 공식 채널 임베드 안내 문구로 대체:
  "[여기에 구단/리그 공식 채널 하이라이트 영상 임베드]"
- 말투는 친근한 구어체, 이모지 적당히 사용

output/naverblog/[날짜]/[경기ID]_post.md 로 저장해줘.
```

**`.claude/commands/write-youtube.md`**
```markdown
data/matches/[경기ID].json 파일을 읽어서 유튜브용 1분 영상 대본을 작성해줘.

규칙:
- 총 나레이션 150~180단어, 60초 분량
- 구성: 훅(5초) → 타임라인 리뷰(30초) → MOM/평점(10초) → 순위변동(10초) → 구독유도(5초)
- 화면에 들어갈 자막 텍스트를 나레이션과 별도로 타임코드와 함께 작성
  (형식: [00:03] "홀란드 오늘도 인간 아님 ㄷㄷ")
- 강조할 키워드(스코어, 선수명, 숫자)는 자막에서 **굵게** 표시
- 결과에 대한 유머 요소 1~2개, 인신공격 금지
- 실제 방송 영상 대신 자체 그래픽 연출 기준으로 작성

output/youtube/[날짜]/[경기ID]_script.md 와 
output/youtube/[날짜]/[경기ID]_subtitles.srt 두 파일로 저장해줘.
```

### 5-4. 자동 실행 스케줄링

로컬/서버에서 정기 실행하려면:

- **Mac/Linux**: `crontab`으로 매일 아침 시간에 `claude -p "/collect-data 실행 후 오늘 경기 전체에 대해 /write-instagram, /write-blog, /write-youtube 순서로 실행해줘"` 같은 명령을 스크립트로 등록
- **GitHub Actions**: 저장소에 자동화 코드를 올려두고, `schedule` 트리거(cron 문법)로 매일 정해진 시간에 워크플로 실행 → Claude Code CLI 호출 → 결과물을 output 폴더에 커밋

두 방법 다 "결과 파일 생성까지"는 완전 자동화하고, 실제 SNS 업로드 버튼은 사람이 최종 확인 후 누르는 걸 추천합니다 (계정 정책 위반 방지 + 오탈자/사실관계 체크).
