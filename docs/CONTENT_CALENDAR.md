- 각 콘텐츠 제작 전 `docs/CLUB_RESEARCH_CHECKLIST.md`로 사실 확인.
- 릴스/블로그 모두 `scripts/generate_*` 로 초안 생성 후 사람이 검수·수정.
- 4주차 종료 후 참여율(저장/공유/댓글)을 보고 5주차부터 유학 정보 콘텐츠 비중을 늘릴지 결정.
